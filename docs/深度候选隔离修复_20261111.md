# RGB-D 匹配检测：逐候选隔离缺深度区域

当夹爪附近亮斑等灰色候选的内部深度不足时，原检测器会退出整帧检测，使同帧独立的有效工件也无法进入跟踪。本次修复在适配层单独隔离这些无效候选，其他工件继续经过原检测、带面准入和 ID 确认。

## 行为与边界

- `isolate_boundary_depth_gaps: true` 的 RGB-D 匹配入口使用新增的 `isolate_candidate_depth_gaps`；原边界专用函数保留原契约，关闭隔离时保留原检测行为。
- 深度要求仍为至少 30 个有效像素、50% 内部覆盖率，以及原有内缩参数。原始 RGB、深度和相机时间戳不修改，不填补缺失深度。
- 被拒绝的内部候选记录在 `candidate_depth_diagnostics.rejected_interior_depth_components`，包含包围框、有效深度像素数及内部像素数。
- 无法观测的候选不认定为已知背景、不分配 ID；同帧其他合格工件可以继续检测和跟踪。
- 没有任何合格工件且仍存在未知缺深度区域时，该帧继续标为不确定，不当作空带，不用预测补充确认次数。
- 同一工件仍需两次不同的真实 RGB-D 观测；重复帧不增加次数，多个有效目标仍保留独立 ID 并接受原多目标检查。

本次提交只包含检测适配层、回归测试和本文说明。相机曝光、现场标定、传送带参数、冻结位置、发送提前量、示教轨迹及机器人执行策略均不在此次提交中调整；原生深度单帧入口保持原获取方式。

在仓库根目录运行：

```bash
  python3 -m pytest -q \
  tests/test_candidate_depth_isolation.py \
  tests/test_boundary_depth_gaps.py \
  tests/test_workpiece_admission.py \
  tests/test_nero7_fused_perception.py \
  tests/test_fixed_belt_association.py \

  tests/test_nero7_occlusion.py \
  tests/test_two_second_diagnostics.py \
  tests/vision/test_nero7_identity.py \
  tests/vision/test_nero7_perception.py
```

测试涵盖亮斑与有效工件同帧出现、深度覆盖率边界、原始像素不变、无效区域不产生目标、真实双帧确认和多目标保留。测试与存档回放不保证实际工件在某个上游位置一定能得到有效深度，也不作为真机抓取成功率。
