# 几何认证测试失败排查（2026-10-31）

## 结论与影响范围

此前 `tests/planning/test_segment_certificate.py` 的 3 项失败，都是测试将 `mujoco.mj_geomDistance` 的返回值当成精确距离造成的。我们复现了一组本应分离的盒体，MuJoCo 3.8.1 返回距离 0，但独立凸优化和分离平面证明它们是分离的。在临时目录安装的 3.3.7 上，相同原始测试也出现 3 项同样的失败；没有修改系统或项目使用的 MuJoCo。

这是本次失败的直接原因，并不代表证明了 MuJoCo 所有接触计算、全部模型上的距离，或项目的其他碰撞功能都正确。MuJoCo 官方仓库有[相似距离异常的报告](https://github.com/google-deepmind/mujoco/issues/3383)，涉及的具体模型和版本与本例不同，不能仅凭相似现象断言内部根因相同。

## 具体复现

盒体对，单位米：

| 度量 | 本次结果 |
|---|---:|
| MuJoCo 3.8.1 的 `mj_geomDistance` | 0 |
| 该调用返回的两个见证点间距 | 0.209631 |
| 独立凸优化最近距离 | 0.204021 |
| 项目 `native_separation_lower_bound` 下界 | 0.195152 |
| 此单一例子禁用 native CCD 后的 MuJoCo 距离 | 0.204021 |

见证点距离不是独立真值，它只表明该次调用的两个输出相互矛盾。独立凸优化以显式构造的盒体顶点为输入；求出可行点距离上界，再用分离平面获得下界，两者间距必须小于 0.2 微米，否则测试直接失败。本例下界小于独立距离，符合预期。禁用 native CCD 只用于本地对照，不是项目修复建议；本次没有改动项目 MuJoCo 标志。

原 3 个失败依次发生于：

1. 检查两几何体的距离变化是否在运动学上界内：MuJoCo 距离无故跳到 0，使测试对差值的断言失败。
2. 盒体间距下界测试：认证下界 0.195 m 与错误的 0 m 比较。
3. 凸网格与盒体距离下界测试：同样把错误的 0 m 当成精确值。

项目的 `native_separation_lower_bound` 使用 MuJoCo 见证点构造一个投影方向，并用完整几何体的投影计算保守下界；它不把这个距离标量直接作为安全间隙。对于凸体，任意有效方向上的正投影间隙都能证明该方向上分离。若方向无效则使用中心方向，不能得到有效方向时返回未知；仍会保留更细检查。本次并未修改生产碰撞代码或取消检查。

## 修复与验证

修复的是三个测试的参考距离：盒体与盒体使用有界凸最小二乘，网格凸包与盒体使用顶点凸组合的凸优化；每次都检查可行性与分离平面上下界的数值差。平面及其他形状的既有检查保留。新增已知间距/重叠测试，并故意注入虚假的 MuJoCo 零距离与见证点，对 60 个重叠和 60 个分离姿态检查下界；重叠时不允许得到正下界。

- MuJoCo 3.8.1：完整段认证测试 44 项通过；全部规划目录测试 471 项通过。
- 隔离安装的 MuJoCo 3.3.7：段认证测试 44 项通过。
- `final_regression.log` 保存最终相关回归结果；`distance_comparison.json` 保存复现数据和 qpos；其余日志在 `runs/geometry_investigation_20261031/`。

独立测试只覆盖这些几何及数值样本，不是对所有机械臂构型的形式化证明。该段认证属于原完整规划路径；当前 `two_second_pick` 的接近与跟随检查依然是 50 Hz 及额外关节细分的离散检查，没有因此变成连续碰撞认证。本次没有连接相机、机械臂或 CAN，也没有发送真机命令。
