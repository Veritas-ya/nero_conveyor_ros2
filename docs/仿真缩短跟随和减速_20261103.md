# 缩短仿真跟随与减速

MuJoCo 两段分别是闭爪后同速跟随（青色）和后续减速（黄色/橙色）。本次在 15 cm/s 设定带速下，使用既有仿真实验参数把两段时长从 0.4 / 1.0 s 改为 0.25 / 0.5 s，抬升仍为 20 cm，实际视觉速度仍来自 RGB-D 卡尔曼。理论段长分别为视觉速度乘跟随时间、视觉速度乘减速时间的一半；轨迹是连续曲线，确认夹持时可在减速段继续进行，抬升前仍需确认。

第一件冻结视觉速度为 14.837 cm/s，对应参考轨迹青色约 3.71 cm、黄色约 3.71 cm；同速下原设置约 5.93 cm、7.42 cm。显示轨迹离散采样，段边界的显示长度略有误差。这些是参考末端位移，不是检测到的物体位移，也不是实际关节运动长度。

结果 `runs/random_five_15cms_20261103/short_follow025_brake05_lift20.json`：前两件各完成夹持、抬升、放入料框和返回。第一件搬运预规划在抬升期间完成并通过复核；第二件的放置候选发生变化，回退为重新规划。第三件在轨迹生成时失败：第一候选两种 IK 采样均不收敛；第二候选在 10 Hz 下的 J6 样条位置超限，50 Hz 回退到达候选预算，其他候选错过发送时限。其余两件未运行。此结果不能证明五件的成功率。

控制周期内应用关节目标速度差得到的最大离散加速度约 5.79 rad/s²（J1）。MuJoCo 2 ms 物理子步速度差峰值约 35.16 rad/s²（J6），受接触、控制和数值求解影响；与规划曲线、物理真机指标不同。该仿真组合不代表真机已验证。
