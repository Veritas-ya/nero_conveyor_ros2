# 示教搬运、投放和返回

该入口可选，不指定示教文件时仍执行原先的规划投放和返回。启用时，抓取和夹持确认后先按原逻辑抬升；从抬升完成的反馈位置规划到示教搬运起点；执行搬运示教至其末端，在此位置张爪投放；从投放后的实际反馈连接到示教返回起点；执行返回示教；最后规划至当前配置的等待位。示教搬运的末端就是投放点，返回段可以从不同的关节位置开始，连接由规划器处理。夹爪动作由程序执行，不记录在示教文件中。

每个连接和示教段都重新检查任务身份和设备反馈。示教七轴位置使用录制的相对时间重新时间参数化，按当前七轴位置、速度和加速度约束检查曲线；搬运段包含当前工件点云载物估计，并采用当前任务冻结曝光的场景及现有配置检查。检查的环境范围取决于 `environment_collision_scope`，现场配置仅检查可见的实测带面等已有规则，**不表示料框、人员或所有现场障碍物已被建模**。示教录制时环境和后续运行时环境必须由现场人员核对。没有真实的示教文件时无法证明料框位置、现场轨迹可行或抓放成功。

## 只读录制两段

机械臂按厂家说明由操作人员以合适的示教方式移动；录制器不发送运动、夹爪、使能或模式切换命令。安排搬运段到料箱上方实际投放位置结束；返回段从投放结束后的位置开始，到接近等待位处结束。每段开始和结束先保持静止，再开始或结束采样；记录完成后检查文件并在现场确认路径。录制器最多按 50 Hz 采样关节反馈；收到的各轴 CAN 包并非严格同一时刻，文件会记录时间间隔和包时间跨度。由于只读记录不判断物理场景，不能将它当作通过现场检查的轨迹。

先在终端执行：

```bash
cd /home/ubuntu22/nero_conveyor_ros2
source /opt/ros/humble/setup.bash
source install/setup.bash
```

准备好搬运示教的起点后，开始只读录制。下面的 30 秒是录制最长时间，可根据需要调整；按 `Ctrl+C` 可提前结束并保存已采集的数据（至少四个有效样本）。录制开始后，用现场设备沿预定路线操作机械臂，在投放位置停稳。

```bash
ros2 run nero_core record_taught_path \
  --config /home/ubuntu22/nero_conveyor_ros2/install/nero_bringup/share/nero_bringup/config/two_second.hardware.legacy_observed.yaml \
  --segment transfer --seconds 30 --hz 20 \
  --output /home/ubuntu22/nero_conveyor_ros2/taught/transfer.json
```

在投放后的返回起点停稳后，开始录制返回段；现场移动至接近等待位并停稳后结束：

```bash
ros2 run nero_core record_taught_path \
  --config /home/ubuntu22/nero_conveyor_ros2/install/nero_bringup/share/nero_bringup/config/two_second.hardware.legacy_observed.yaml \
  --segment return --seconds 30 --hz 20 \
  --output /home/ubuntu22/nero_conveyor_ros2/taught/return.json
```

文件不允许覆盖，重新录制请使用新文件名。录制时若无有效关节反馈或时钟重置则不保存；记录包含关节顺序、弧度、时间基准、TCP 和机器人模型哈希、料框 ID、CAN 及固件配置。读取时核对这些来源，防止把别的机械臂、TCP 或料框的文件静默用于当前任务。录制不使能机械臂；若厂家模式不广播关节反馈，需要先解决反馈来源，不能假装录制成功。

## 配置检查和抓取

可以先仅检查文件和配置，不连接设备：

```bash
ros2 run nero_core two_second_pick \
  --config /home/ubuntu22/nero_conveyor_ros2/install/nero_bringup/share/nero_bringup/config/two_second.hardware.legacy_observed.yaml \
  --check-config \
  --taught-transfer /home/ubuntu22/nero_conveyor_ros2/taught/transfer.json \
  --taught-return /home/ubuntu22/nero_conveyor_ros2/taught/return.json
```

配置检查只检查文件的格式和来源；真正的接入和示教段认证发生在每次抓取运行时，依赖当前任务的机器人反馈和冻结观测。以下使用用户最近指定的 16 cm/s 固定带速。要恢复视觉测速，删除 `--fixed-belt-speed-m-s 0.16`：

```bash
OPENBLAS_NUM_THREADS=1 ros2 run nero_core two_second_pick \
  --config /home/ubuntu22/nero_conveyor_ros2/install/nero_bringup/share/nero_bringup/config/two_second.hardware.legacy_observed.yaml \
  --fixed-belt-speed-m-s 0.16 --execute --count 1 --preview \
  --taught-transfer /home/ubuntu22/nero_conveyor_ros2/taught/transfer.json \
  --taught-return /home/ubuntu22/nero_conveyor_ros2/taught/return.json \
  --output "/home/ubuntu22/nero_conveyor_ros2/runs/two_second_hardware/taught_$(date +%Y%m%d_%H%M%S)"
```

机械臂若不在等待位，启动时会尝试自动回位。记录文件中的相对时间可整体放慢以满足约束，所以实际示教回放时间可能长于录制时间；插值曲线会经过采样点，但两点间不承诺与人工拖动的轨迹完全一致。生成曲线和连接都需通过当前已有检查。只有现场完成录制及验证，才可评估真实投放是否成功。
