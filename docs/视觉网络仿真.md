## 本次结果

一次固定输入：seed 1543、1 件类别 12、传送带设定 0.1 m/s，出生位置 x=-1.28 m。渲染画面由 Nero7 处理，在仿真 6.3–9.2 秒、目标 track 0 的 86 个合格测速报告中，水平速度中位数 **0.098746 m/s**，范围 0.098535–0.098800 m/s。设定速度与视觉估计分开；这不是独立误差评估。

确实运行 GPU 模型：生成 512 个候选，1 个通过该历史入口的候选筛选。模型加载 **8.213 s**；目标推理 **2.109 s**，候选筛选 **0.273 s**，曝光到候选交付对应的仿真时间约 **2.962 s**。启动时没有完成模型预热，实际首轮推理可能包含首次运行开销；不能把这些数值简单相加当端到端时延。模拟运行 25.01 s、墙钟 54.18 s，实时因子 **0.462**。最终对象以 `ik_unreachable` 失败，未抓取、未投放。进程状态 `completed` 表示运行结束，并非任务成功。原始记录在 `runs/vision_network_migration_20261027/`；摘要和来源哈希在 `vision_migration/`。

70 项视觉身份、投影、测速及输入完整性测试通过。ROS 2 包构建和 `vision_sim --help` 已检查；实际 GPU 运行使用独立 Python 环境通过源码执行，未验证 ROS 安装环境中的 CUDA 依赖。图像来自仿真渲染；输出中的 `source` 或预测零不应被视为实际测速精度。

## 运行

需要 Python 3.10、MuJoCo、CUDA/PyTorch 及 GraspGen-X 依赖。官方 GraspGen-X 源码及许可证已随新项目提供；大型权重不复制，必须显式提供包含 `gen/epoch_736.pth`、`dis/epoch_1056.pth` 及各自 config 的目录。启动会核对权重大小和 SHA-256。使用与 CUDA 兼容的独立 Python 环境，不需要以旧项目目录作为 Python 源码路径。

```bash
cd /home/ubuntu22/nero_conveyor_ros2
export NERO_GRASPGENX_CHECKPOINT_DIR=/absolute/path/to/checkpoints/release
export PYTHONPATH="$PWD/src/nero_core"
export MUJOCO_GL=egl OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
/path/to/cuda-python -m experiments.graspgenx_sim.nero7_run \
  --objects 1 --seed 1543 --belt-speed 0.1 --moving-approach continuous \
  --max-sim-time 25 --no-video --output "$PWD/runs/vision-new-run"
```

输出目录必须不存在。`--viewer` 需要图形桌面和可用 DISPLAY；本轮无窗口，未验证可视化窗口。输出 `nero7_reports.json` 保留捕获时刻、轨迹及速度资格，`inference/` 保留输入与网络结果，`result.json` 包含物理评分及实时因子。默认编码器带速与模拟真值不作为视觉测量输入；每次视觉测速仍有最少观察样本与资格条件。
