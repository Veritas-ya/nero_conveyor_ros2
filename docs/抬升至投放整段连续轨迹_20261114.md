# 抬升至投放整段连续轨迹

当前直接投放入口将“抓取减速终点 → 抬升 → 边搬运边转向 → 固定姿态进入投放位”编译为同一个 `TimedPath`，共享任务身份、版本、时钟和发送器。到达实际投放位后张爪，确认释放后执行独立的空爪返回。

## 本次改变

此前已经一次发送预计算路径，但抬升和投放接近分别做局部平滑：两处连接速度约 0.07～0.08 rad/s（最大单轴速度），仍容易看起来接近停住。

现在保留原抬升关键点、路径绕行关键点、投放接近点和最终示教关节位置；收集所有内部连接，在整个搬运链上一起做五次多项式平滑及统一时间缩放。抬升点使用进入方向切线，投放接近点使用离开方向切线，减少在接近点之后转向。整体 q/v/a 连续，起点和最终投放点 qd/qdd 为零；内部连接不设全轴静止条件，不逐点等待到位或重新规划。

轨迹仍由现有 IK、RRT 和逆向固定姿态末段提供几何路径；统一编译不意味着用一条直线代替它们。不能无条件保证任何几何路径都能不停通过，五种连接强度均不满足现有约束时会报告失败，不会把带停顿的退回路径标为连续成功。

新字段 `direct_drop_continuous_carry: true` 已写入两套现场配置，要求 `direct_drop_orientation_first: true`。只有带 `--experimental-direct-drop-guard` 的直接投放入口采用该整段策略。原启动命令不变；使用新进程加载安装版配置和源码。

## 保留的时序边界

- 整段搬运可提前从预测的减速终点规划；实际夹持及载物复核通过后接入。
- 本次没有合并抓取减速轨迹和载物轨迹。因此原来的闭爪跟随、减速、夹持确认及起点复核仍存在，不能宣称闭爪后所有停顿均已消除。
- 仅在最终投放到位后开爪；开爪期间复核实际释放后的返回路径，再执行返回。没有把夹持状态切换隐藏在连续关节流中。
- 当前配置的抬升高度、框沿几何、关节约束和最终投放关节不变。框沿仍是现有名义换算，并非本次重新做了物理标定。
