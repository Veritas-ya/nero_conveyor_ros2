## 固定带速辅助 ID 关联

填写 `--belt-speed-cm-s` 或 `--fixed-belt-speed-m-s` 后，共用感知工厂会用显式给定速度、配置带向和实测带面法向构造关联运动先验。在相机的实际采集时间间隔内先扣除已知带速造成的位移，再由原卡尔曼门限关联剩余位置差异。对外保留原帧检测中心和原始时间戳。

目标仍需至少两帧真实观测确认。预测和缺帧不增加观测次数；重复或乱序帧不更新观测时间；遮挡歧义、超时换ID和几何/时序检查继续生效。关联先验不标为视觉测量，固定速度报告保留 `visual_velocity_used=false`、`measured_velocity_base_m_s=null`，日志增加 `association_prediction_source` 和 `id_confirmation_source`。

未显式给定带速的视觉测速分支保持原算法。原生深度和RGB不补点或修改，原机器人自体过滤算法及其外扩参数继续保留。

## 粗算优先独立入口（2026-11-11）

## 主机校时后的恢复基准（2026-11-11）

抓取中反馈时钟代次变化仍取消本次任务并退出旧发送器。恢复检查只在完整的法兰、四组关节及夹爪接收时间证据证明是同一次主机日历时钟跳变时，等待新代次的连续稳定反馈；不将时钟代次解释为机械臂重启次数。

恢复基准更新要求：所有必要报文均有有效的 `host_monotonic_from_can_unix` 映射、时间不倒退且符合原200ms新鲜度限制；代次统一增加一次，各路日历时间与单调时间偏移变化一致；取得至少100ms、至少3组各报文均更新的真实反馈，关节变化范围不超过0.001rad，关节距最后已发送目标不超过原1°阈值，且FK/法兰一致性检查通过。最多只读等待0.5s，等待期间不发送运动或夹爪指令。

通过后只替换执行器的反馈检查基准，继续原有带载判断、稳定保持、示教投放与返回或空载回位路径检查；原抓取轨迹不恢复执行。接收适配层的时间映射、冻结观测时间和相机时钟代次均不改写。重复报文不增加稳定观测时间；时间映射不确定、反馈倒退/过期、再次校时、FK或位置持续不符、设备故障与用户取消仍拒绝恢复。

日志新增 `recovery_clock_wait` 和 `recovery_clock_rebased`，记录主机跳时量、稳定观测窗口与位置误差。两种冻结入口和粗算优先入口共用本次执行器修复；90ms提前量、现场标定、等待位和示教文件未调整。
