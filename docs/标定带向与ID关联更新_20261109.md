## 固定带速辅助 ID 关联

填写 `--belt-speed-cm-s` 或 `--fixed-belt-speed-m-s` 后，共用感知工厂会用显式给定速度、配置带向和实测带面法向构造关联运动先验。在相机的实际采集时间间隔内先扣除已知带速造成的位移，再由原卡尔曼门限关联剩余位置差异。对外保留原帧检测中心和原始时间戳。

目标仍需至少两帧真实观测确认。预测和缺帧不增加观测次数；重复或乱序帧不更新观测时间；遮挡歧义、超时换ID和几何/时序检查继续生效。关联先验不标为视觉测量，固定速度报告保留 `visual_velocity_used=false`、`measured_velocity_base_m_s=null`，日志增加 `association_prediction_source` 和 `id_confirmation_source`。

未显式给定带速的视觉测速分支保持原算法。原生深度和RGB不补点或修改，原机器人自体过滤算法及其外扩参数继续保留。

## 构建和启动

在检出本次提交的工作区中构建：

```bash
cd /home/ubuntu22/nero_conveyor_ros2
source /opt/ros/humble/setup.bash
colcon build --packages-select nero_core nero_bringup
source install/setup.bash
```

仅检查当前匹配配置和43.5cm/s带速，不连接相机或机械臂：

```bash
OPENBLAS_NUM_THREADS=1 ros2 run nero_core two_second_pick \
  --config /home/ubuntu22/nero_conveyor_ros2/install/nero_bringup/share/nero_bringup/config/two_second.hardware.tracked_freeze.yaml \
  --belt-speed-cm-s 43.5 \
  --check-config
```

匹配版连续真机抓取，包含现有示教轨迹：

```bash
OPENBLAS_NUM_THREADS=1 ros2 run nero_core two_second_pick \
  --config /home/ubuntu22/nero_conveyor_ros2/install/nero_bringup/share/nero_bringup/config/two_second.hardware.tracked_freeze.yaml \
  --taught-transfer /home/ubuntu22/nero_conveyor_ros2/taught/session_20261104_223416/transfer_trimmed_start025_20261105.json \
  --taught-return /home/ubuntu22/nero_conveyor_ros2/taught/session_20261104_223416/planned_return/return_generated.json \
  --belt-speed-cm-s 43.5 \
  --continuous \
  --execute --preview \
  --output "/home/ubuntu22/nero_conveyor_ros2/runs/hardware_tracked_$(date +%Y%m%d_%H%M%S)"
```

带速参数单位为cm/s。发送提前量已在配置内设为50ms，重新启动进程后读取；改带速时填写实际测得的值。以上路径以现场工作区为准，换目录时调整配置和示教路径。
