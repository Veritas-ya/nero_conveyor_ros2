# 仿真实时点云与抓姿

`tools/probe_measured_network_scene.py --viewer` 打开 MuJoCo 窗口，在实际运行的仿真画面中叠加视觉数据。青色球点是当前 Nero7 目标掩码对应的单帧 RGB-D 深度反投影；橙色线是网络选择的 TCP 和进近方向示意。抓姿在后续帧按原方法用观测点云中位数的变化平移，方向保持网络选中的方向；不是用仿真物体位姿平移。长时间没有新观测时隐藏叠加层。线框的 80 mm 跨度只供辨认方向，不代表夹爪宽度或碰撞体积。

这个入口是视觉与 `full_preplanned` 的**只读诊断**：它运行真实的 GraspGen-X 网络和完整规划，但不发送仿真机械臂动作。规划拒绝、窗口关闭或达到仿真时间时结束。点云来自理想仿真 RGB-D，未模拟曝光运动模糊，本入口没有使用 Fast-FoundationStereo。它不证明物理抓取成功。

在有图形桌面的终端运行（外部权重和 CUDA Python 使用已有安装）：

```bash
cd /home/ubuntu22/nero_conveyor_ros2
export PYTHONPATH="$PWD/src/nero_core:$PWD/src/nero_bringup"
export NERO_GRASPGENX_CHECKPOINT_DIR=/absolute/path/to/checkpoints/release
export MUJOCO_GL=egl OPENBLAS_NUM_THREADS=1
/path/to/cuda-python tools/probe_measured_network_scene.py \
  --viewer --seconds 25 --output /tmp/nero-live-result.json \
  --capture-output /tmp/nero-live-last-frame.npz
```

本机可将上述 CUDA Python 路径替换为 `/home/ubuntu22/桌面/nero-agx-conveyor-sorting-main/traditional_pipeline_linux_20260928/experiments/graspgenx_sim/.venv/bin/python`，将权重路径替换为该目录下 `checkpoints/release`；算法代码从本项目加载。这只是使用既有外部运行环境和模型资产，不要求从旧工程导入算法源码。

无窗口实测在仿真运行中实际提取到最后一帧 2143 个目标点和经视觉跟踪更新的网络 TCP，且已通过 MuJoCo 显示几何创建检查。当前执行环境没有 `DISPLAY`，未验证 GUI 窗口显示或刷新性能。该次 `full_preplanned` 结果因交付时已错过轨迹起始时间而拒绝，未执行抓取。
