# 轨迹检查调整为 50 Hz（2026-10-31）

真机配置和 `--hardware-conditions` 仿真模式的**规划阶段**轨迹几何与 TCP 参考采样频率设为 50 Hz。5.8 秒轨迹的时间采样由 1161 个降为 291 个；阶段边界独立保留，若相邻采样点的关节跨度大于 0.008 rad，仍在两点间细分。因此实际几何检查次数可能大于时间采样数。IK 节点仍为 10 Hz，必要时回退 50 Hz。连续多项式 q/v/a 峰值检查保留。

实际发送目标仍为 100 Hz。执行线程根据实际反馈对每个发送时隙做的检查并未变成 50 Hz；该检查与规划阶段采样是两条不同路径。

## 离线时间对照

以历史真实 RGB-D 两帧（271、301）、固定预测带速 0.0595 m/s，默认及候选等待位分别运行 200 Hz 与 50 Hz，每种条件各 6 次，依次交替，共 24 次。默认等待位的规划中位数从 **0.974 s 到 0.542 s**；仿真换算候选等待位从 **0.712 s 到 0.350 s**。这些耗时不包括图像检测、机械臂运动与实时通信；检测和规划都在不连接设备的条件下进行，起始关节是假设。

所有回放均成功交付轨迹，同一场景对应的候选选择一致；两帧、两种等待位的第一组对照中，501 个时刻的关节位置、速度、加速度采样一致。`runs/geometry_50hz_20261031/` 下保存逐次结果和轨迹采样。

这是采样率调整，并非连续碰撞证明：50 Hz 的采样可能漏掉出现在两个采样点之间的短暂碰撞或 TCP 偏差，即使有按关节跨度的细分也无法排除。自动化测试包含一个 50 Hz 漏掉而 200 Hz 检出的合成窄碰撞，用来明确这个边界；两帧结果一致不证明其他场景也一致。

## 仿真与测试

使用 50 Hz 几何采样、0.0595 m/s 固定预测速度和随机横向位置/偏转，MuJoCo 连续两件 T-LESS 7、5 均完成物理夹持、抬升、投放及返回。两件拦截规划耗时约 0.365 s 和 0.413 s；第二件 50 Hz 时间网格为 291 点，关节跨度额外细分后执行了 336 次几何状态检查。详细信息见 `runs/geometry_50hz_20261031/simulation.json`。仿真采用未辨识的重力补偿和伺服参数，不是现场实机验证。

380 项相关离线测试通过；两个 ROS 包构建、配置检查通过。源码和安装模块哈希一致。本次没有连接相机或机械臂，也没有发送真机命令。
