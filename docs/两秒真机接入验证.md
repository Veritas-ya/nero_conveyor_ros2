## 已完成的代码接入

| 环节 | 实现 |
|---|---|
| 共享算法 | 仿真与真机共用原 `Intercept` / 曝光年龄预测；可见 OBB 纯几何函数移入核心，旧仿真接口保留 |
| 实测输入 | 一次 Orbbec SDK 捕获；视觉线程读取缓存；沿用原生点云、带面、自体过滤和 Nero7 XY Kalman；两模块共享现场工件高度上限 |
| 抓姿与预测 | 冻结同曝光 OBB、相对抓姿与速度；分别保存物体坐标、TCP 相对变换、预测接触点与实际反馈 |
| 抓取规划 | 两秒直线＋闭合跟随；原 IK 和有界回退；候选依次尝试，取消和预约过期可打断 IK 及采样检查 |
| 路线检查 | q/v/a 多项式极值；加密采样的直线偏差、自碰撞、实测场景、带面间隙与载物点云检查 |
| 实际发送 | 复用原 Hardware、MotionLease、FeedbackClock、JointStreamSender；厂家 j/js 位置 API，不使用理想执行器 |
| 任务流程 | 等待位确认→接近→跟随闭合→宽度/力确认→抬升→RRT 绕行至配置料框→检查张爪→放料→返回→新目标 |
| 证据 | 原 ExecutionTrace 记录原曲线 q/v/a、准备目标、SDK 起止、反馈原始与映射时间；结束发送后写盘 |

真机载物变换由旧视觉预测和机械臂实际 TCP 建立，属于估计；不再使用 MuJoCo 物体真实位姿或接触真值。运动学和碰撞镜像仍使用 MuJoCo 模型，未推进仿真来伪造反馈。释放后只保留释放瞬间几何估计，未重建落入料框的实际姿态。
