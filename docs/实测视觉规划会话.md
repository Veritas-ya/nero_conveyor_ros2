# 实测视觉规划会话

`nero_core.measured_motion.MeasuredMotionSession` 将原有的 `MovingTargetTracker`（仅 Nero7 XY Kalman 速度）、`translate_bound_network_grasp` 和 `NeroMovingPolicyContext` 接起来。它不打开设备、不发送命令，也不自动启动 ROS 节点。调用方应先确认任务身份，并逐帧输入经过同一相机时钟映射的检测与测速报告。模拟数据只能作为测试输入，不能当成真实测速。

- 几何帧和 Nero7 报告使用原跟踪器的序号、设备时间、主机采集时间和时钟代次校验；任务身份另绑定轨迹 ID 和代次。未提供可信速度时不会使用固定带速。
- 异步抓姿结果须匹配同一任务、已接受的采集时间、帧序号及目标点云摘要。保留最近 64 个帧的摘要，较早结果会被拒绝；绑定后不会由晚到结果替换。抓姿采用原算法根据后续实测目标点云中位数平移，保留网络姿态和抓取偏移。
- `install_latest_scene` 使用原 `RobotModel.install_scene` 过滤已接受帧的场景；场景令牌绑定任务、曝光时间、帧序号、时钟代次和过滤后场景及目标点云摘要。`create_full_context` 保留该令牌对应的捕获时目标几何，允许同一目标的较新视觉观测到达，并要求已绑定网络抓姿、有效的实测速度、`full_preplanned` 和 `continuous` 模式及原 `FullPlanSceneMonitor`。它创建原始完整规划上下文；实际完整规划 worker 由原策略调用。本次离线测试只验证可创建上下文和 worker，没有证明轨迹认证成功。
- 时钟代次变化使会话永久失效；显式 `cancel()` 使后续快照不可用并拒绝晚到回调。调用方仍必须同步停止发送器、取消原策略中的规划并关闭上下文，不能仅凭会话取消就认为执行已经停止。

调用方必须提供来自同一曝光的目标和背景点云、相机标定及对应机器人场景状态；接口核对帧头，并绑定过滤后的目标和场景数组，但无法独立证明调用方给出的背景点云确实来自该帧。它不会自动更新背景，也不能替代运行中的场景变化监控。安装场景和构造规划上下文期间不持有跟踪锁。新帧到达后保留原捕获时间及其目标几何，跟踪器持续使用新观测；相机编号、标定、内参、外参、图像尺寸或时钟代次不一致时拒绝。上下文必须启用原场景监测器，原策略在执行前要求该监测器用近期配对的场景覆盖具体认证轨迹。场景监测并非遮挡区域的证书，运行中仍需验证相机与反馈的实际时间映射。场景安装墙钟耗时单独记录在令牌的 `install_wall_s`，与并行推理耗时不可简单相加。采集时间与策略时钟必须已转换为相同单调时间域；设备时间只用于帧对应关系。真实设备适配和 ROS 实时接线仍未完成。

离线测试中的目标、测速、反馈和场景是受控替身；没有运行物理夹持、投放，不能视为真机或物理仿真成功。真实抓姿网络的独立仿真结果见 [视觉网络仿真](视觉网络仿真.md)，此前的视觉结果接到仿真完整规划请求的诊断见 [视觉到完整规划](视觉到完整规划.md)。

## 本轮场景绑定增量

新增帧头和场景摘要检查，并在场景过滤、上下文准备结束后重新检查任务和相机绑定。新帧不会单独导致丢弃旧快照；取消、时钟或相机绑定变化导致拒绝，取消后晚到上下文关闭。相关测试使用受控视觉输入和机器人模型，其中真实 `RobotModel.install_scene` 与真实完整规划 worker 的创建路径已运行，但未提交这条路径的完整规划请求，也没有完成物理抓取。

## 本轮并行快照与场景复查

同一相机的新观测到达时，场景快照保持其真实曝光时间及对应目标点云，策略上下文使用原移动目标跟踪器的最新观测；执行前复用旧 `FullPlanSceneMonitor` 对具体计划及剩余轨迹进行新可见障碍复查。场景监测是构造该上下文的必需输入，需要提供同一相机的帧读取、校准、曝光主机时间转换和带面区域。原监测器必须能取得与帧时间配对的机器人反馈；否则不能通过执行前场景门控。

测试使用受控合成观测，调用原场景过滤器、实际移动策略上下文、实际规划 worker 和实际场景监测器；覆盖快照生成时更新、新观测年龄、缺少监测器、标定变化和取消。此测试没有执行完整规划或物理闭环，也没有验证高帧率实际吞吐。

本次回归：视觉与规划测试共 543 项通过；加入捕获抓姿摘要检查后会话测试 9 项复测通过；ROS 2 Humble 三个包重新构建通过。没有连接硬件，也没有在本轮运行新的端到端物理抓取。
