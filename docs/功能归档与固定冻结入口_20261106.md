# 当前功能与固定冻结入口（2026-11-06）

此次归档包含目前工作区内的示教回放、轨迹平滑与预计算、返回反馈复核、完整组件点云处理，以及固定位置单帧获取功能。现场配置原样保存，未因上传而调整机械臂参数。

示教轨迹及哈希见[轨迹清单](../taught/README.md)。当前使用42点截取投放段和61点离线返回段，保留原始录制、生成报告及会话来源。旧 `taught/transfer.json`、`taught/return.json` 是历史文件，不是当前YAML选择的轨迹。

`fixed_freeze_pick` 只替换原真机入口的目标点云获取，复用规划、发送、夹持、示教投放、返回和取消恢复。它使用固定输入带速、原生深度单帧定位，不等待跨帧ID确认或视觉测速。实际机器人反馈仍按原规则配对到原始曝光并剔除机器人自身点云。

固定冻结以完整工件中心在原始曝光中的位置为准：入口上游50～48cm，保留原始曝光时间。轻量定位与完整提取的搜索区域覆盖实测原生深度带面凸包，修正旧2/98%分位数矩形在上游约46～47.5cm截断的问题。完整提取按同帧触发像素选择组件，避免其他位置的候选直接阻断；原有尺寸、同帧重叠、曝光年龄及后续规划认证仍生效。
