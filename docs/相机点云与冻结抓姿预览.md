# 相机点云与冻结抓姿预览

默认只打开 Orbbec RGB-D 相机。加 `--read-robot-feedback` 时被动读取机器人反馈，用原有自体过滤及场景过滤处理点云；既有 Hardware(execute=False) 适配器禁止所有 CAN 发送，不使能、不运动机械臂或夹爪。相机未连接时保留窗口，每5秒重新尝试连接。

```bash
cd /home/ubuntu22/nero_conveyor_ros2
OPENBLAS_NUM_THREADS=1 PYTHONPATH=src/nero_core \
DISPLAY=:1 XAUTHORITY=/run/user/1000/gdm/Xauthority \
python3 -u tools/view_live_grasp.py
```

左上是实时RGB；左下是满足冻结条件的原曝光及其OBB/夹爪方向叠加。右侧可以左键旋转、滚轮缩放：灰色为实时场景点云，青色为冻结工件点云，绿色为可见OBB，橙色为所选几何抓姿候选，黄色点为冻结时测速器的实测位置，黄色线为冻结速度对应0.5秒位移，紫色点为候选TCP。白色为第一个通过空间窗口检查的时长对应的预测接触点和跟随终点；若全部失败则显示第一个时长，并明确报告失败。带面上的线标出冻结区上游边界、抓取入口和跟随区末端。

自动冻结沿用生产入口的单个合格轨迹、测速跨度至少0.45秒、有效观测年龄、入口上游0.35m及1.5秒规划预留规则；再次提取同曝光工件点云并关联该测速轨迹，复用OBB候选生成。速度来自原Nero7 XY卡尔曼，并按实测带面补足切向Z分量。窗口预测沿用配置的2/3/4/5.5/6.5秒时长和0.8秒跟随。冻结是感知预览事件，不代表已经交付可执行轨迹。

冻结以后，工件点云和抓姿保留在原曝光位置，不随实时画面移动；界面持续显示该曝光距今时间。实时场景可以继续变化。空格或“重新等待冻结”会清除快照及测速历史；下拉框查看四个候选，Esc关闭。相机时钟代次或几何改变会清除旧冻结，断连也会清除画面，不把旧结果显示为当前结果。

每次启动默认使用`runs/live_camera_grasp/上海时间戳/`新目录；每次冻结保存JSON参数、NPZ点云和原始RGB PNG。`session.json`记录是否发生真实冻结及最后状态。

默认相机模式不读取机械臂反馈，无法执行依赖实际关节姿态的机器人自身点云过滤；可用下方只读反馈模式复用原过滤链。两种模式都不做IK、整条轨迹碰撞认证或最终候选选择。遮挡或机械臂进入相机视野可能造成检测差异；不能用配置等待关节冒充实际姿态。橙色夹爪按配置张开宽度绘制，仅示意方向，候选不代表实际可夹持性。实际相机外参、TCP和带向仍依赖当前配置及现场有效性。

## 2026-10-30 预览修正

未冻结时也持续显示实测目标OBB与抓姿；RGB上标出原Nero7跟踪位置和ROI。逐轨迹显示观测数、跨度、不确定度和拒绝原因，记录采样间隔及处理耗时。几何提取和原场景过滤分别用独立worker，不阻塞测速；重采和时钟变化使旧worker结果失效。

目标点云继续调用迁入的原 `detect_target`、`shape_pick`、`BeltSurface`；存在同曝光配对的实测机器人反馈时，使用原 `RobotModel` 自体过滤，并调用 `install_scene` 的范围裁剪、自体、饱和、深度边缘、背景、双目一致性、密度与体素处理。右侧此时显示原链最终保留的场景点，附曝光间隔。没有实测反馈时，明确标为原始场景参考，不以配置等待位代替实际状态。OBB显示已从带面局部系转换到机器人基座系。

读取实际反馈并使用旧点云处理链的命令（只读，无CAN发送）：

```bash
OPENBLAS_NUM_THREADS=1 PYTHONPATH=src/nero_core \
DISPLAY=:1 XAUTHORITY=/run/user/1000/gdm/Xauthority \
python3 -u tools/view_live_grasp.py --read-robot-feedback
```

`--replay-stem /absolute/path/frame_000302` 可离线查看历史RGB-D与当时保存的机器人反馈，不连接任何设备。历史单帧只显示几何，不能积累有效测速。诊断保存于当前运行目录的 `diagnostics.jsonl`。离线历史帧验证不能替代连续过件实测。

## ID前的实测深度检查

预览现在先验证深度候选，再交给原Nero7跟踪器分配ID。候选使用当前曝光已经注册到RGB的原生深度，经真实相机内参/D2C和现场外参转入实测带面坐标系；继续使用既有`DepthGeometryVisionPipeline`的12mm至配置高度上限（当前120mm）、70像素、12mm至160mm平面尺寸范围，以及原带面轮廓内25mm条件。绿色带面不作为工件；具备实测机器人反馈时调用既有自体过滤。

未通过的候选在诊断中记录真实离带高度范围、保留点数与拒绝原因，不进入跟踪器、不分配物块ID。通过者仍使用原前端的实测中心与时间戳，原卡尔曼参数不变。此ID表示通过几何筛选后的轨迹身份，不是物块类别识别。

入口通过可选`candidate_filter`接入，预览显式启用；其他未传此参数的历史/实机入口维持现有行为，本次没有默默改变它们。历史302曝光的原3个候选经检查保留1个、拒绝2个；单帧不能验证多帧测速或连续过件。
