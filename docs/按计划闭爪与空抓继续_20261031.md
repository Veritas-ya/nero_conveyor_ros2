# 按计划闭爪与空抓继续（2026-10-31）

## 实现

真实配置和仿真对齐模式选择 `closure_policy: scheduled_attempt`。完整轨迹先由规划器生成并认证，执行时到达接触参考时刻即发送夹爪闭合；预测位置、方向、相对速度和剩余跟随时间继续记录为诊断，不再决定是否闭爪。原有 100 ms 指令提前量仍然生效，实际闭爪发送时刻记录在事件日志中。

如果跟随结束时夹持未确认，继续发送已规划的跟随后减速轨迹至终点，不把视觉预测的工件假装成已夹持载物。该模式执行时不按目标点云再次判定接近轨迹，执行中的带面、机器人本体、关节/时间和有效反馈检查仍存在；规划阶段的目标点云和几何检查也仍存在。因此规划失败、轨迹过期或这些检查未通过时仍可能不运动，并不是保证任何条件下都会运动。

到达减速终点后，若夹持未确认，报告 `attempt_completed_grip_unconfirmed` 并停在终点：不声称夹持成功、不进入抬升投放、不启动下一件。若宽度和受力确认夹持，沿用原有的载物规划、抬升、投放和返回流程，仍不将反馈闭环当成实物成功的独立证明。

配置可用 `closure_policy: feedback` 恢复原有误差门限和夹持确认策略；缺省为 feedback。真机现场配置与仿真对齐模式均显式使用 scheduled_attempt。旧等待位配置仍是默认，另外的仿真换算等待位候选没有覆盖它。

## 离线验证

- 在理想反馈测试替身中，无论反馈闭合条件是否满足，都按参考时刻发送闭爪。模拟空爪继续进入减速并交付终点；已夹持时仍建立载物估计。空爪结果只算完成尝试，不进入抬升。
- MuJoCo 正常工件：T-LESS 7，真实仿真带速和固定预测速度均为 0.0595 m/s；按计划闭合，完成夹持、物体抬升、投放和返回。结果 `runs/scheduled_attempt_20261031/simulation_normal.json`。
- MuJoCo 人为产生空抓：实际仿真带速 0.0595 m/s，故意将预测速度设为 0.04 m/s。计划时刻闭合，未确认夹持，继续执行至完整减速终点并返回状态 `attempt_completed_grip_unconfirmed`，没有抬升。结果 `runs/scheduled_attempt_20261031/simulation_miss.json`。该预测速度差仅用于离线测试，不改变现场设置。
- 仿真使用渲染 RGB-D 和物理接触/载物评估，重力补偿及位置积分内环为未辨识的仿真设定；这不是实机验证。仿真不连接 CAN 或相机。
- 运行期间曾更新条件审计字段的文字；两份已保存仿真记录中的 `condition_audit.closure_policy` 文本是当时旧名称，实际启用的模式由配置、`close_feedback_would_allow`、事件和运行代码确定，现有代码已修正审计字段。

当前版本 ROS 包构建、配置检查与回归测试的输出在 `runs/scheduled_attempt_20261031/`。没有发送真机命令，也未验证真机能否在当前现场按此轨迹执行。
