# 减速终点搬运预规划

抓取轨迹交付后，发送监督线程启动独立进程，从**已认证抓取曲线的减速终点七轴位置**预测抬升、投放和返回路径。该工作与预约等待、接近、闭爪和减速重叠。子进程独立持有模型和场景，不获取设备，不发送控制指令，不改变当前机械臂的规划器状态；模型及示教时序在打开相机/CAN之前预热一次。

## 实际执行的交接

1. 预测的载物附着只是假设：采用冻结目标点云在计划跟随结束时的预测位置，转换到该时刻计划 TCP 坐标系；再随夹爪到减速终点。不能将工件继续沿带速外推到搬运终点，也不能用抓取点的关节状态作为抬升起点。
2. 抓取闭合及夹持反馈逻辑保持现有实现。实际夹持时保存实际关节 FK 与冻结视觉预测形成的载物估计；减速结束后已有的到位确认仍生效。
3. 候选已经完成时，核对任务身份、场景版本、原抓取轨迹版本及任务令牌，核对实际关节相对原指令终点的既有 1° 容差；用实际开口和本次实际载物估计重新检查搬运、投放张爪及返回几何。此阶段复用曲线，不重做路径搜索。
4. 若预测失败、实际载物不满足候选几何或候选到减速终点仍未完成，则丢弃预规划，使用原实际状态规划流程。取消/时钟重置不会采用迟到结果。待完成的预测进程收到取消信号；同一服务不能同时提交两个预测任务。
5. 确认后原执行器接管轨迹版本及发送所有权。释放后仍检查实际释放估计下的返回路径。夹持确认、急停和执行监测不由预测结果替代。

`carry_lookahead_enabled: true` 已写入两个现场配置。它依赖平滑抓取曲线与已加载的投放目标、预计算搬运流程。原启动命令可使用；`--experimental-direct-drop-guard` 仍单独控制直接投放实验。未带该参数时，提前准备的是当前示教搬运流程。
