# 视觉抓姿到完整规划输入：离线桥接

`nero_core.vision_full_bridge.prepare_full_observation` 将经原 `validate_candidate_admission` 检查的网络候选与当前视觉观测对齐，复用旧项目 `GraspTrackOverride`、`SavedNetworkObservationView` 和 `tcp_prediction` 表达物体观测、相对抓姿和预测抓姿。函数只产出规划观测输入，不构造轨迹、不发送指令、不为碰撞或夹持作保证。

调用方传入捕获时冻结的 `TargetIdentity` 和当前活动身份，二者必须完全一致；任务、几何版本、目标或代次变化和取消均拒绝。再执行旧视觉检查：目标、场景、代次、观测年龄及结果年龄；年龄限制由调用方明确提供，不新增抓取阈值。网络 TCP 始终与**网络曝光时的视觉目标位置**绑定，而当前观测与速度保留原时刻。输入的所有时间应在同一仿真捕获时钟；ROS、设备和主机时钟转换未在此实现。输出分别保留 `object_observed_pose`、`object_current_estimated_pose`、`current_ee_grasp_pose`、`predicted_ee_grasp_pose` 与 `tcp_to_object`；输入不会被原地修改。此绑定只支持原适配器的平移跟随和固定网络方向，不声称估计工件旋转。

## 保存观测重放

读取 `vision_network_warm_20261027` 真实保存的网络候选、Nero7 报告和反馈记录，未重新访问设备或网络。网络曝光 **6.268 s**；Nero7 最近观测 **7.334 s**；结果接纳 **7.350 s**。到接纳时，网络输入年龄 **1.082 s**，当前视觉观测年龄 **0.016 s**，速度为 `[0.09874835, 0.00003000, 0] m/s`。桥接将网络曝光时 TCP 和同曝光目标位置的偏移应用到当前视觉位置，保留两种时间。未来 TCP 仅按保存的视觉速度与原规划时间重建；它是规划输入，不是实测机械臂位置。实际关节反馈单独保存在 `vision_full_bridge/saved_observation.json`。测试只使用记录的视觉点、输出及反馈，未取模拟物体真值。

复现（需要独立准备的保存运行数据）：

```bash
PYTHONPATH=src/nero_core python tools/replay_vision_full_bridge.py \
  --run runs/vision_network_warm_20261027
```

## 验证与尚缺工作

- 79 项视觉、时间、身份和桥接相关测试通过；包括取消、旧任务、旧几何版本、目标切换、跟踪代次、场景变更和观测过期拒绝。
- 149 项原完整规划和执行相关测试通过，包含一项使用原完整策略 `_make_planning_request` 的桥接测试：检查目标按原视觉观测时刻外推到预约时刻，并保留身份。该项用受控模拟状态和测试 worker，**没有完成这条候选的碰撞认证或物理抓取**。
- ROS 包重新构建，安装后可以独立导入桥接模块。

当前 `prepare_full_observation` 尚未接入 ROS 视觉任务节点或实时仿真策略；调用方须同时将身份设置到原策略使用的 `env.target_identity`。旧仿真 `TargetGeometry` 使用模拟器已知完整目标几何，不能把它当成当前可见点云认证。保存网络候选的闭合宽度为 0，原完整抓取认证要求正的名义载物宽度；原显式 contact-handoff 模式允许零宽，但仅认证接近前缀，闭合确认和载物路径仍须原流程执行及认证。不能自行将 0 替换成估计物体宽度，亦不能把前缀证书称作完整抓放证书。

后续要将实际视觉线程输出、活动身份和可见点云场景接入原完整规划 worker，再按原条件比较目标、路径和认证结果；经认证后才接入物理执行。当前没有新的物理试验，也未改变原安全、速度或夹持参数。
