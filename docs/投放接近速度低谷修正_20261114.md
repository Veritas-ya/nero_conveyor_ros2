# 投放接近速度低谷修正

接近投放位的短暂卡顿，主要对应参考曲线在料框前约 20 cm 的速度低谷。上一版虽然已是一条 q/v/a 连续曲线，但仍要求准确经过这个辅助关节点，并给它一个较小的通过速度；连接前后分别减速、加速，因此“连续”没有消除可见的低速段。

## 实机记录依据

检查 `runs/two_second_hardware/direct_drop_20261114_195520` 的三次搬运：

- 三次均使用整段搬运，每次只调用一次发送流，接近料框时没有重新规划或内部到位等待。
- 参考曲线在同一空间位置先明显降速，再加速进入投放点。
- 只有第 2 次出现一次 FK 反馈重读，耗时约 6.7 ms；第 1、3 次没有该事件，所以反馈重读无法解释三次同位置的减速。
- 实际发送间隔峰值分别约 40.8、45.7、52.5 ms。这些调度间隔仍可能影响实机平顺性；本次没有宣称发送抖动已被消除。

## 修改

`continuous_carry.py` 将料框接近点标记为可圆滑经过的**规划辅助点**。`carry_blend.py` 使用一段五次多项式跨过原接近点，衔接两端原曲线的位置、速度和加速度，不再强制经过该点的低速度条件。

抬升点、必要的路径节点、起点和最终投放点仍保留。先处理这些必要点的连接，再从更新后的曲线采样构造辅助点过渡，避免两个平滑区重叠时产生 q/v/a 跳变。较宽的过渡不满足几何时会缩窄重试；全部不通过仍报告规划失败。

修改只用于 `direct_drop_continuous_carry` 的直接投放流程。框沿与载物认证、最后水平 10 cm 内投放方向要求、关节位置/速度/加速度/jerk 限值，以及到位后立即开爪逻辑不变。没有新增加速度差分发送检查。日志中 `terminal_start_s` 现在明确标注为原辅助点的时间标记；实际过渡范围记录在 `bin_approach_rounding`，不再把辅助点误称为必经点。

## 同一实测输入的离线对照

每件均使用其自身的冻结点云、规划身份、夹持时关节反馈及减速终点反馈；法兰由模型重建。对照为同输入重新规划的旧连接方式和新连接方式，**不是将新曲线当成已执行的真机反馈**。

统计区域为离最终投放点水平距离 10～30 cm。TCP 速度由解析关节曲线导数和 MuJoCo 雅可比计算，未使用指令差分；0.1 m/s 仅用于报告低速持续时间，不是新增控制阈值。

189 项相关测试通过；ROS `nero_core`、`nero_bringup` 构建成功。测试覆盖重叠平滑区 q/v/a 连续、必要点保留、最终姿态、关节极值、取消及几何失败、真实载物复核、释放顺序和多周期日志配对。本轮未连接相机/CAN，未运行真机或物理抓取；真实平顺性仍需下一次执行验证。

同时修正了离线回放工具原来用 `glob()` 首项选择点云/轨迹、固定读取第 1 周期反馈的问题。现在按周期与 `planning_delivery.identity` 配对，缺失或重复数据明确报错。该问题属于离线分析工具，不是在线抓取身份关联错误。

## 复现与使用

原直接投放启动命令不变，退出旧抓取进程后重新启动才会加载本次安装版。未带 `--experimental-direct-drop-guard` 的示教投放入口不采用这次圆滑辅助点策略。

```bash
cd /home/ubuntu22/nero_conveyor_ros2
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 PYTHONPATH=src/nero_core:tools \
python3 tools/replay_bin_approach.py \
  --config src/nero_bringup/config/two_second.hardware.legacy_observed.yaml \
  --guard src/nero_bringup/config/calibration/bin_rim_nominal_20261114.yaml \
  --runs runs/two_second_hardware/direct_drop_20261114_195520 \
  --cycles 1 2 3 \
  --output runs/diagnostics/bin_approach_recheck
```

输出目录需尚不存在。原始结果位于 `runs/diagnostics/bin_approach_20261114/` 和 `runs/diagnostics/bin_approach_20261114_regression/`，包括报告、曲线系数、TCP 解析速度、后台复核及源码哈希。原始 RGB-D 和大体积运行记录保持本地保存，不随源码发布。
