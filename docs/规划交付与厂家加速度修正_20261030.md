- `CellConfig`支持有明确来源的`manufacturer_joint_acceleration_limits_rad_s2`能力数组。现场配置同时显式请求8，并记录`user_reported_manufacturer_spec_20261030`。未配置厂家能力的历史入口继续使用原默认值；非法数组、无来源或超过所配能力的请求仍拒绝。
- 规划时间参数化、整曲线q/v/a极值、跨阶段实际发送历史和厂家适配器的请求记录共用现场数组。厂家适配器没有新增加速度写入命令。
- 相邻几何小段不再重复检查公共端点。原200 Hz时间点和最大0.008 rad关节细分全部保留；不同时间、不同阶段或另一场景仍重新检查。额外细分内部也检查取消。
- 本件冻结后，视觉线程保留同一相机接收及时间代次监测，暂停未被本件使用的测速、检测与OBB重复计算。返回成功后才恢复下一件，并要求新曝光、重置卡尔曼历史；旧目标消费标记保留。在途旧帧不能发布覆盖活动任务。
- 几何进度新增采样序号、总数和轨迹时刻。每个候选的失败阶段、部分阶段耗时、最后进度和剩余发送预留均保存；区分`candidate_budget`、`send_deadline`、`global_planning_budget`及取消。
- 实测去重后空场景认证约1.41 s、IK约0.41 s，原1.5 s私有预算仍不足，现场改为2.5 s。公共场景准备另计；全局8 s和实际入区前100 ms截止继续限制每个候选，没有顺延过期轨迹。
