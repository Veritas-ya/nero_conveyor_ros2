## 实际接入

- 入口：`tools/run_two_second_grasp.py`；参考：`experiments/two_second_grasp/smooth_reference.py`；平滑规划、认证与反馈门控：`smooth_execution.py`；载物/返回复用 `placement.py`；精简报告：`simulation_report.py`。
- 感知使用渲染 RGB-D、原 Nero7 身份关联及 XY 卡尔曼测速，抓姿使用单帧可见点云 OBB。**该入口未调用 GraspGen-X 或其他视觉网络**，不把传送带设定速度作为测量值。
- 接近使用五次位置曲线与五次姿态进度：静止起步、接触时匹配冻结速度，闭合期间继续跟随，确认夹持后才允许执行减速段。空间路径通常稍有弯曲，已改变原严格直线匀速策略。
- 求解收紧到位置 `1e-7 m`、方向 `1e-6 rad`，使用原 DLS 与有界最小二乘回退，去掉该实验求解器的零空间居中漂移。数值精度不代表相机或机械臂的实际精度；真机求解器未切换。
- 七轴完整样条经过 q/v/a 多项式极值检查；发送端采样同一条样条，保留原控制器的离散位置、速度、加速度与停止包络检查，记录是否限幅。
- 保留提前 100 ms 发送。接近段从参考起点前 100 ms 开始采样，后续段也从零进度接入，避免直接跳到参考的第 100 ms。
- 闭合使用当前真机执行器已有的水平 22 mm、竖直 12 mm、方向 0.25 rad 判定，以及 0.25 s 预测漂移检查；没有增加独立速度阈值。减速前要求原有的 0.4 s 持续确认，并读取真实 MuJoCo 双指接触和夹爪电机反馈。
- 仿真默认跟随改为可配置的 **0.8 s**：原 0.6 s 在扣除实际闭合时间、100 ms 提前发送后，仅剩约 0.34 s 持续确认，试跑因此正确停止。真机的跟随时长没有随之修改。
- 载物减速依据当时实际夹持姿态在私有 `MjData` 检查；只允许已有带面支撑在原 2 mm 接触过渡范围内持续，不能穿过其他障碍物。抬升、搬运、返回也对最终执行样条做采样几何检查。几何检查仍是离散采样，不能冒充连续碰撞或动力学证明。
- 抬升/搬运/返回按实际软件限制重新定时，从上一段静止指令终点连接；阶段转换仍检查实际反馈。RRT 同一直线关节弦上的加密点不再逐点停车：只合并数值共线点，保留所有拐点和反向点，最终曲线重新检查。
- 物理成功要求双指受力、实际工件离开带面、料框碰撞几何内稳定支撑且脱离手指，最后检查返回关节误差；`grasp_assist=False`，没有将工件焊接到夹爪或重置其姿态。

## 已完成的物理试跑

随机种子 1543，本轮验证的工件为 T-LESS 类别 12；**仅证明该工件在这些条件下成功，不保证任意工件或连续五次成功**。下表来自最终算法的两个独立物理运行：

| 条件 | 2 秒平滑方案 | 低加速度方案 |
|---|---:|---:|
| 记录 | `viewer_2s.json` | `low_acceleration_merged.json` |
| 带速设定 | 0.10 m/s | 0.05 m/s |
| 接近 / 跟随 / 减速 | 2 / 0.8 / 1.5 s | 6.5 / 0.8 / 2 s |
| 七轴加速度软件配置 | [8,8,9,9,10,10,12] rad/s² | 每轴 0.15 rad/s² |
| 接触时 TCP 跟踪误差 | 4.49 mm | 1.99 mm |
| 实际工件抬升 | 196.4 mm | 195.8 mm |
| 料框稳定放置 / 返回 | 通过 / 通过 | 通过 / 通过 |
| 返回最大关节误差 | 0.00760 rad | 0.00750 rad |
| 控制器限幅次数（全流程） | **0** | **0** |
| 搬运 / 返回参考时长 | 1.897 / 2.183 s | 12.138 / 12.403 s |
| 主机运行耗时 / 仿真结束时刻 | 36.43 / 26.72 s | 58.71 / 67.36 s |

低加速度运行的全流程实际应用**指令差分加速度**峰值为 0.14413 rad/s²，未超出 0.15 配置。MuJoCo 的物理关节 `qacc` 峰值约 31.2 rad/s²；位置执行器响应和接触冲量不受参考的加速度约束直接限制。这两种测量分别保存，**不能据此宣称实际机器人关节加速度也被限制为 0.15**。

0.15 是当前真机配置的软件值，不是厂家额定值；低加速度试跑只是采用相同数值限制，仿真的坐标、等待姿态和物理模型仍与现场不同。之前保存任务的 5.5 秒运动学通过也不保证每次渲染点云产生的 OBB 都通过。本轮另一次 5.5 秒尝试遇到 IK、加速度和关节位置限制，均在发送前拒绝，记录保留。

低加速度的拦截规划总耗时 3.103 s；抬升、搬运、返回的完整规划耗时分别为 1.123、2.047、1.262 s。这些阶段在持物等待时规划，使用仿真时钟执行。IK/qva、几何耗时是拦截总耗时的组成部分，不重复累加；主机墙钟与仿真秒数不互相替代。详细字段在各 `.summary.json` 中。

## 在用户电脑运行

沿用项目依赖与模型资产；此入口从新项目导入，不需要旧项目目录。运行不使用现场 SDK。先切换目录：

```bash
cd /home/ubuntu22/nero_conveyor_ros2
```

打开可视仿真，2 秒平滑接近、带速 10 cm/s（终端需处于桌面会话）：

```bash
PYTHONPATH=src/nero_core:src/nero_bringup OPENBLAS_NUM_THREADS=1 \
  python3 tools/run_two_second_grasp.py --profile smooth \
  --count 1 --belt-speed 0.1 --seconds 90 --viewer --hold-viewer \
  --output runs/my_smooth_mujoco.json
```

测试每轴 0.15 rad/s²，允许更长的接近和减速（此处只覆盖仿真）：

```bash
PYTHONPATH=src/nero_core:src/nero_bringup MUJOCO_GL=egl OPENBLAS_NUM_THREADS=1 \
  python3 tools/run_two_second_grasp.py --profile smooth --count 1 \
  --belt-speed 0.05 --approach-s 6.5 --follow-s 0.8 --brake-s 2 \
  --sim-acceleration-limit 0.15 --seconds 180 \
  --output runs/my_low_acceleration_mujoco.json
```

退出可关闭 MuJoCo 窗口或按 Ctrl+C。`--hold-viewer` 会在试跑结束后保留画面；最终状态显示在左上角。青色点云和橙色 OBB 是**冻结曝光**，绿色/青色/橙色线分别是接近、跟随、减速的规划参考，不是持续更新的点云或真实工件轨迹。

JSON 保存物理反馈、实际控制器指令、限幅、阶段计划与放置验证；同名 `.summary.json` 供快速检查。控制记录时间是 `env.data.time` 的步进后快照，不能冒充精确硬件发送时间。最新可视运行额外记录环境构建、首步和感知、详细日志保存耗时；此前记录缺失的计时留空，不倒推捏造。
