# 真机点云视觉测速接入

`two_second.hardware.legacy_observed.yaml` 由此前 4.53 cm/s 固定速度切换到 `velocity_source: pointcloud_xy_kalman`。原有融合检测、工件准入、身份关联及跟踪保持原位；对同一曝光、同一连通工件、有效非带面深度点计算基座坐标的 5%～95% 分位范围中心，用与原滤波器相同的噪声、采样和资格参数更新独立 XY 卡尔曼。原滤波器仍运行并提供对照，跟踪和目标抓姿位置、OBB 与场景点云没有替换。

轨迹预测使用新滤波速度，日志保留原速度、点云测速位置、采集时间、样本跨度、身份与来源。有效速度仍须来自当前相机曝光及原目标的有效关联；丢失、身份变更、相机时钟重置和重置跟踪时不得复用旧点云速度。按实测带面法向补齐 Z 速度，未使用预设带速。固定速度仅在用户显式提供 `--belt-speed-cm-s` 或 `--fixed-belt-speed-m-s` 时覆盖。

## 验证范围

- 目标点云、双滤波器身份/时间隔离和源切换的合成测试，不连接相机和 CAN。
- 仿真中九组 RGB-D 采样事后对照，以及一件点云卡尔曼控制的完整抓放；详见[仿真诊断](仿真视觉测速位置诊断.md)。这是合成相机结果，不保证真机精度。
- `runs/observation_diagnostics_20261103/real_rgbd_pointcloud_replay.json` 使用保存的 19 帧实拍数据，5 帧提取到已准入目标点云。录制每约 15 帧保留一帧，保持原时间戳回放后无连续合格速度，因此只能验证数据管线、不能验证实机测速误差或抓取表现。
- 本次未连接真实相机或机械臂、未发送任何机械臂命令；真实连续速度和运行时延尚待实测。

```bash
source /opt/ros/humble/setup.bash

```

输出应显示 `velocity_policy.source` 为 `pointcloud_xy_kalman`，`hardware_connections` 和 `commands_sent` 均为 0。不要沿用包含固定带速参数的旧命令，否则会覆盖视觉速度。
