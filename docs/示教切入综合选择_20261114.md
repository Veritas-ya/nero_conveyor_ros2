# 按距离、时间和平滑程度选择示教切入点

`taught_entry.py` 提供多候选选择，并已接入预计算搬运代码，但配置 `taught_entry_search_enabled` 默认关闭，当前真机配置不启用。启用时必须同时启用投放示教和预计算搬运，并显式配置 `taught_entry_indices`：必须包含原始切入点 0，最多五个候选。候选索引必须保证后续至少四个采样。模型启动时预计算候选时序，不缓存场景或载物的认证结论；非零候选无法生成时序可跳过，零号候选失败或任务取消则停止。

计划抬升轨迹后，以抬升轨迹终点关节位置和 TCP 位姿作为预测起点。分别计算候选 TCP 位移及关节距离，并针对每个候选生成和检查带载连接及剩余示教段，保留投放终点。对通过检查的候选，分别按照 TCP 距离、连接加剩余段总时长、完整候选关节加加速度峰值从低到高排名，取三个排名之和最小者（同分优先总时间较小者）。这是等权排序启发式，不是物理最优解；单位不同的三个量没有相加。每项数值、拒绝原因和所选索引记录在连接段诊断中。

连接和后缀使用原有 q/v/a 连续认证及规划参数范围，连接处仍是零速，不能称为无停顿融合。后缀从新起点重新插值，保证通过原后段采样点，不保证每处等于原始多项式；每次必须重新检查本次载物和任务冻结场景。回程仍使用当前独立逻辑。

## 历史场景验证

`tools/replay_taught_entry_selector.py` 对五组历史数据测试原索引 0、5、10、15，使用生产选择函数，全部候选通过当前项目检查，五组均选择索引 5；此组接入加后缀平均约 2.072 s，原索引 0 平均约 2.238 s。四个候选的时序准备总计约 4.59 s，发生在启动阶段。多候选逐项规划与验证平均约 0.668 s；原固定切入计算平均约 0.145 s。将本次离线计算时间和运动时间粗略相加，动态搜索并未缩短总时间；两组计时来自不同批次，不能作为实机保证。

当前示教投放的既有配置允许 10000 rad/s³ 的关节加加速度，选择的后缀峰值约 9225 rad/s³，仅代表模型曲线解析值，不能证明实际机械平稳。实际是否卡顿还与轨迹端点零速和发送时序有关。历史点云没有料框几何，工件是估计载物，起点是历史抬升后指令锚点；不证明真实料框避让、物件稳定或现场安全。应先补充料框与载物的现场验证，并降低逐个候选规划的等待成本，才考虑启用真机动态选择。
