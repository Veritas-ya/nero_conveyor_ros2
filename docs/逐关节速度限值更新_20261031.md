# 逐关节速度限值更新

依据用户提供的 NERO7 最大关节速度：J1–J3 180°/s，J4–J7 225°/s，上位机规划与发送限制分别设为 π 与 1.25π rad/s。配置来源标记为 `user_supplied_nero7_joint_specs_20261031`；此说明不声称已经读取或验证实际设备固件限值。

配置读取器支持有来源的逐轴能力边界：上位机按 `speed_percent` 比例校验，不代表厂家设备内部以相同比例限速。没有显式能力边界时，保留旧的 `PickSettings` 逻辑。可选厂家限值查询现在按每轴实际请求值比较；当前配置默认不执行此查询。此修改不会修改固件参数，厂家 `move_j` 自动回位行为也不由上位机逐点限速约束。

空载加速度仍为 8 rad/s²，载物加速度仍为 2 rad/s²。用户提供的速度上限不能证明加速度限制正确或消除发送时序问题；上次失败记录按新速度上限仍会因指令加速度 −11.18 rad/s² 超过 8 而被拒绝。

233 项相关离线测试通过，`colcon build --packages-select nero_core nero_bringup` 和 ROS `--check-config` 通过，install 配置与源码 SHA-256 一致；检查输出设备连接和指令数均为零。没有进行仿真抓取或真机运动验证。近期碰带原因、现场 TCP 与带面标定仍未解决。启动脚本现在会加载提高后的上位机速度限制，轨迹可能比之前快。
