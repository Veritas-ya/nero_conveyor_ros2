- 原帧缓存、局部目标深度、原生场景过滤、树复用、体素分组优化均保留，未改动原阈值。旧代码的 `full_pick_replanning`、worker、发送租约、反馈时间映射及原认证器仍在；此次执行原代码测试，不代表它们已连入 ROS 新任务节点。
- 使用线程屏障测试推理与场景确有重叠，且选择器消费同一个准备结果；不以两阶段耗时之和作为交付耗时。测试后端和选择器是替身，该测试仅验证调度。
- 旧测试的完整规划、执行门控、未来接续、worker/场景认证等四组共 **148 通过，8.01 秒**；其中有合成模型和模拟反馈，不是物理成功证明。原有核心及新增桥接测试 **127 通过，4.61 秒**。两组是不同测试集，不相加表述成独立功能通过数量。
- 用 2026-10-23 保存帧、保存的 Fast 输出和 GraspGen-X 候选回放。在与旧报告相同的历史选姿条件下，目标掩码、1828 个目标点、选中抓姿、44799 个场景代表点以及体素索引和覆盖误差逐值一致，详见 `evidence_20261027/comparison.json`。网络输出为保存数据，不包含 GPU 实际推理；旧报告是同输入的另一轮输出，非同一新代码两版本同时比较。
- 另用连续接近配置运行新桥接、仅提供返回空的速度观测：原筛选器拒绝全部候选。1024 个候选方向的记录中，506 条为张开手指与带面间距不满足、442 条 TCP 高度不足、76 条拦截 IK 失败。此结果同时改变了选姿条件且没有真实速度，不能单独归因于速度缺失。保留完整 `current_selection_rejection.json`，不放宽原条件。
