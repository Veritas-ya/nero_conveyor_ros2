# 倾斜工件抓取仿真：2026-10-30

本次目标：工件生成时绕世界 Z 轴旋转 35°，随后由 MuJoCo 接触和传送带模型推进；不对它施加持续旋转力，也不在运行中改写工件姿态。生成时的姿态是仿真场景参数，不提供给抓取控制器。抓姿由渲染 RGB-D 的单帧可见 OBB 产生，网络未调用。

传送带设定 0.0595 m/s，预测速度也明确使用操作者固定的 0.0595 m/s，而非视觉估计。当前仿真入口仍等待视觉轨迹测速有效才冻结目标；这比现场固定速度模式的轨迹资格要求更严格，不能说两者完全相同。本次终端中旧文案“冻结视觉速度”有误；JSON 里 `speed_source: operator_fixed_belt_speed`、`visual_speed_used_for_prediction: false` 和控制输入 `[0.0595, 0, 0]` 为实际数据，文案已修正供下次运行。
