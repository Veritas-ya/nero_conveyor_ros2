# 单件固定带速实验：5.95 cm/s

> 历史记录：2026-10-31 用户将现场速度改为 5.9 cm/s；当前现场配置使用 0.059 m/s。下方的 0.0595 命令只对应当时的实验，运行时会覆盖当前配置。

用户提供传送带当前速度为 **5.95 cm/s = 0.0595 m/s**，要求本次不采用视觉测速并尝试一件。新增明确的单件运行参数，默认配置和原视觉测速分支不变。

```bash
cd /home/ubuntu22/nero_conveyor_ros2
source /opt/ros/humble/setup.bash
source install/setup.bash

OPENBLAS_NUM_THREADS=1 ros2 run nero_core two_second_pick \
  --config /home/ubuntu22/nero_conveyor_ros2/install/nero_bringup/share/nero_bringup/config/two_second.hardware.legacy_observed.yaml \
  --fixed-belt-speed-m-s 0.0595 --count 1 --execute --preview \
  --output "/home/ubuntu22/nero_conveyor_ros2/runs/two_second_hardware/fixed_595_$(date +%Y%m%d_%H%M%S_%N)"
```

先检查参数时将 `--execute --preview` 替换为 `--check-config`，不会连接设备。固定带速模式仅支持 `--count 1`。删除该速度参数即恢复配置中的默认视觉来源。数值是 **m/s**，误填 `5.95` 会超出已配置速度工作范围而被拒绝。

## 实际使用的速度与观测

- 本次预测使用 `operator_fixed_belt_speed`，不采用相机估计的速度，也不等待视觉速度有效标记、样本数量或 0.45 s 测速窗口。
- 相机继续提供实际曝光时间、当前位置、目标点云、身份关联和 OBB 抓姿；目标必须已确认、当前可见、唯一且曝光新鲜，反馈时间配对与上游规划窗口检查保留。
- 原 Nero7 卡尔曼内部仍随位置/身份跟踪运行；其速度只是参考遥测，不进入本次规划或速度资格判定。没有把用户给定值伪装成相机测速结果。
- 已配置 XY 运动方向结合实测带面补齐高度方向，再归一化为表面速度 0.0595 m/s。沿带面运动两秒为 119 mm；预测仍从曝光时刻算起，包含进入轨迹前的观测年龄。
- 终端显示“用户设定 5.95 cm/s”；共享预览将该值标为“用户设定带速”，同时将原视觉速度标为“不用于本次控制”的参考。
- 速度覆盖只写入当前运行的有效配置和日志，不修改现场 YAML，也不修改传送带电机设置。

实测带面环境范围、自碰撞、提前工件接触、q/v/a、时钟/取消、版本和发送所有权等检查保持现状。固定速度不会强制发送已被拒绝的路径。

## 本轮准备与离线结果

证据目录：`runs/fixed_speed_pick_20261030_212327/`。

- 回归：**189 passed，5.35 s**，包括速度来源、倾斜带面单位速度、观测年龄、跳过测速资格但保留其他门槛、拒绝伪装测速、默认分支不变、预览与简短终端标注。
- ROS：`nero_core`、`nero_bringup` 构建通过，1.44 s；7 个变更算法/界面文件与安装版本哈希一致。
- 安装后的检查模式识别固定 0.0595 m/s；省略参数仍为 `nero7_xy_kalman`。两次检查设备连接和命令均为 0。
- 实机只读 CAN 检查有效：等待位最大偏差约 **0.002°**，夹爪开口约 **99.8 mm**、力约 **0.07 N**。只读适配器禁止 CAN 发送，没有自动使能或运动。
- 单独相机检查保存了 `current_camera.png` 和 `camera_preflight.json`，随后关闭该检查连接。画面中带面未见工件，机械臂旁有人，因此尚未启动抓取入口，需完成放料及人员退开后再继续。

历史 `test_20261030_211030_068761885` 保存输入增加固定速度反事实重放：使用原点云和 OBB，将预测速度改为 0.0595 m/s；报告明确标为 `counterfactual_speed_override: true`，不声称历史物体实际以此速度运行。原运行缓存的带面未保存，重放使用同帧重新拟合带面及模型还原的起点反馈。

该重放仍未交付完整轨迹：前两个两秒候选在约 1.145 s 和 1.035 s 进入手指原 4 mm 接触余量（分别 3 点、1 点，均未进入本体凸包）；其余两秒候选受关节曲线速度/位置约束拒绝；三秒候选在认证中达到发送截止，总规划约 4.312 s。改变输入速度并未单独消除既有的路径/接触问题。
