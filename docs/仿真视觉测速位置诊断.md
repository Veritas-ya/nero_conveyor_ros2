# 仿真视觉测速的位置诊断

本次只修改 MuJoCo 仿真实验，不改真机。以 `--sim-observation-diagnostics` 将每个采集时刻的目标二维轮廓中心、深度中位数、原三维位置和几种可见点云中心写入仿真日志；独立评估器的物体位置只供事后比较，绝不输入跟踪或控制。模拟器物体位置每 0.5 秒记录、在图像时间插值，因此比较结果有插值近似误差。

## 发现

对五个 15 cm/s 样本和四个不同姿态/带速的补充样本，重算的“二维中心射线 × 中位深度”与旧观测点一致（最大差异小于 1e-9 mm，限于此模型的无畸变投影）。三维点的速度偏差因此发生在旧观测构造或其输入，而非后续坐标换算本身。分解 `x = camera_x + depth * ray_x` 时，改变的深度对不同样本有不同贡献，不能据此单独断言是哪一个物理因素造成的。旧观测跟踪的是可见轮廓与中位深度的组合，并不保证对应工件上的固定点。

同时比较同一已检测目标点云的均值、中位数、以及 XYZ 各轴 5% 和 95% 分位的中点；在九个样本、对应采样区间按相同时间戳做位置直线拟合后，旧位置的速度平均绝对误差为 0.175 cm/s，分位范围中心约为 0.070 cm/s。随后对两种位置各自使用相同的卡尔曼参数，同帧离线回放的冻结附近速度平均绝对误差为 0.186 与 0.104 cm/s，九个样本均减小；这九组数据仍不足以证明任意形状、遮挡、真实噪声或不同相机下都成立。

这不是绝对工件中心的校准，也不能消除点云缺失、非刚体、分割错误或视角变化导致的所有偏差。深度与点云坐标均为模拟相机测量，验证真机仍需独立的精确参考、标定和不同运动/工件的数据。每个控制周期输出的是观测到的目标点云，不读取模拟器物体真值。

## 接入与回退

默认仿真 `corrected_kalman` 在维持原有目标检测、身份关联和资格检查的同时，使用同帧目标点云分位范围中心更新独立的视觉卡尔曼滤波器。原检测输出和原卡尔曼同时保留作比较。该中心仅用于测速，不替换抓取 OBB、抓取点、场景点云或轨迹碰撞覆盖。`kalman_accel_noise_std` 保持 0.002，未引入预设传送带速度或真值。`--sim-visual-speed-estimator kalman` 可使用原始滤波器；`--sim-speed-position-source legacy_center` 可以令新滤波器使用旧位置；`--sim-visual-speed-estimator constant_fit` 可使用恒速拟合。

诊断数据、计算方法和对照见 `runs/observation_diagnostics_20261103/analysis.json`、`holdout_analysis.json`、`kalman_comparison.json`。其中 20 cm/s 补充实验仅用于观测分析，抓取规划因同步抓取窗口不可行提前结束，不能宣称已验证 20 cm/s 抓取。

## 控制链仿真

`corrected_kalman_live.json` 实际以修正位置的卡尔曼速度控制一件工件，完成抓取、投放和返回。`percentile_center_live.json` 使用相同修正位置加恒速拟合，完成五件连续抓取、投放和返回；该五件并非五次修正卡尔曼控制。原卡尔曼与修正位置恒速拟合的相同冻结帧事后对照见 `percentile_center_live_comparison.json`。仿真成功不能推断实机成功。
