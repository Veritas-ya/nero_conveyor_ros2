# 完整规划运行状态

当前项目的物理仿真入口默认 `continuous`、`full_preplanned`，命令行拒绝 `legacy`。视觉网络的历史控制入口已停用：`vision_sim` 和 `vision_full_trace` 在加载网络、创建渲染器或执行物理动作之前返回错误，不会自动切换旧控制器。旧算法源码与历史结果保留供迁移核对。

## 可运行的完整规划物理诊断

```bash
cd /home/ubuntu22/nero_conveyor_ros2
source /opt/ros/humble/setup.bash
colcon build
source install/setup.bash
ros2 launch nero_bringup physics.launch.py output:=/tmp/nero-full-plan-new
```

输出目录必须不存在。此入口使用模拟历史观测、物体目录抓姿和仿真物体几何；它不运行 Nero7、GraspGen-X 或 Fast-FoundationStereo，因此不能宣称视觉抓取闭环。默认物体从传送带上游 x=-1.28 m 出现，默认速度为仿真值 0.04 m/s。无真实相机、机械臂或 CAN 连接。

## 本轮验证

一次 16 s 离线物理诊断为了更快进入规划，将出生位置显式设置为 x=-0.4 m，不代表默认上游完整过程。配置实际记录为 `planning_mode=full_preplanned`、`selection_policy=first_safe`、`replan_policy=event_triggered`、`moving_approach_mode=continuous`。规划结果报告成功，路径和连续段检查均通过，规划计算墙钟约 0.433 s；随后物理执行时原反馈/实时几何门控判为 `full_pick_feedback_or_live_geometry_invalid`，转入恢复，未闭合、未抬升。`completed` 只是运行结束，不是抓取成功。原始记录 `/tmp/nero-full-preplanned-only-02/continuous/` 可能被系统清理。
