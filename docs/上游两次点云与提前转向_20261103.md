# 仿真上游两次点云与提前转向

同步接入仿真默认启用两次观测：同一相机的首个合格视觉轨迹帧提取目标点云，利用 OBB 的短轴/长轴与 180° 对称候选规划等待位预转；再次使用后续新帧提取点云、OBB 和卡尔曼速度，执行原有拦截及抓取。第一帧只影响预转姿态，不拿第一帧位置冒充抓取位置；后续选中抓姿与第一次不同，剩余姿态变化在接入中连续完成。每次记录时钟代数、目标 ID、轨迹代数、帧号和两次点云。目标身份变化时放弃旧的预转结果并重新检测；正在运动时沿已认证路径先到终点，再重取新目标。

预转期望 0.5 s，但先对关节轨迹时间参数化和检查，受限时会延长；用上一段的关节命令终点作为连接起点，等待当前关节到位并以新场景复核，然后执行，不能直接从某个中间样本跳入。固定 TCP 位置和旋转参考使用项目现有精度门限检查。相机持续采样；未发送真机指令。

命令显式指定 `--early-visual-orientation` 可启用；`--no-early-visual-orientation` 可关闭。为兼容旧仿真命令，若显式传入 `--rotate-before-approach-s` 且未指定早期观测开关，沿用旧单次冻结策略；在双观测模式中，`--early-rotation-s` 控制期望的上游预转时长，后续接入会处理两帧姿态差异。双观测模式下模拟进料改为机械臂返回后从上游产生下一件，避免上次投放期间进料导致预转机会耗尽；因此本次不再声称保留此前提前进料的节拍优势。

15 cm/s、五件随机 T-LESS 的可视仿真记录为 `runs/random_five_15cms_20261103/two_observation_connected_wait.json`。前三件完成抓取、抬升 20 cm、投放与返回；第四件抓取并抬升约 20.76 cm 后，载物放置规划前 32 个候选未找到有效目标逆解而停止，第五件未开始。该失败与本次提前抓姿规划是不同阶段；不能把本轮当作五件成功。

第一件早期点云时间为 0.334 s，最终冻结 4.900 s，早期轨迹规划为 0.85 s（请求为 0.5 s），两帧最终选中方向相差约 68.34°；第四件相差约 77.93°。相差值包含不同帧的 OBB 估计及不同候选选择，不能全部归因于测量误差；对于近对称物体，早期帧本身可能不能可靠确定唯一抓取方向，提前转向也不保证后续无需调整。第二件视觉 ID 变化后重新获取姿态，未合并成同一轨迹。所有记录的控制步的 `clipped` 为 0；该诊断不能代替实际机器人动力学或真机验证。
