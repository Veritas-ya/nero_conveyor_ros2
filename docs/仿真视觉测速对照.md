# 仿真物体速度与视觉测速

`tools/view_sim_velocity.py` 固定传送带设定速度 0.1 m/s，使用 MuJoCo 的自由关节线速度作为物体真实速度，使用同一曝光帧的原 Nero7 XY 卡尔曼估计作为视觉速度。将基座坐标系估计旋转到世界系，比较沿带面世界 X 方向的有符号速度。真实值在独立评估字典采集，绝不进入视觉、跟踪、规划或控制；仅对同一曝光时间、明确的物体身份进行配对，丢弃无匹配记录。画面左上角的两种物体速度均对应显示的曝光时刻，而非当前设备瞬时值。

```bash
cd /home/ubuntu22/nero_conveyor_ros2
PYTHONPATH=src/nero_core:src/nero_bringup MUJOCO_GL=egl \
python tools/view_sim_velocity.py --viewer --hold-viewer --seconds 18 \
  --output runs/visualization/velocity_comparison_paired.json
```

本次记录覆盖仿真曝光时间 6.168 至 16.000 秒，258 条有效配对；带速在整个运行期间实际保持 0.1 m/s。平均绝对视觉误差 0.001572 m/s，最大绝对误差 0.014733 m/s。最后一帧物体真实 X 速度降低至约 0.08155 m/s，不能根据该数据直接断言原因。离开视野或没有合格视觉测速时不造数，也不显示过期点云。运行中的视觉速度采用的同一个算法和相机处理，不加载抓姿网络、不执行抓取、不连接硬件。

JSON 含完整三维速度、时戳及偏差；CSV 汇总沿传送带方向。截图或曲线并非物理抓取验证。
