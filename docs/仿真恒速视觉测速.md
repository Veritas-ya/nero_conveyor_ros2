# 仿真恒速视觉测速

该实验假设每件工件在冻结到抓取期间速度恒定、不打滑，只用于 MuJoCo 仿真。每个视觉身份（时钟代、目标 ID、跟踪代）独立累计相机观测的世界坐标 XY 与采集时间，并在线计算最小二乘直线斜率。拟合只使用截至当前帧的真实视觉位置；不使用传送带设定值、模拟器物体位置或未来帧。重复和倒序时间戳不参与拟合。拟合残差是位置拟合误差，不是速度误差的可靠置信区间。

后续新增了点云位置修正，`tools/run_two_second_grasp.py` 默认使用 `--sim-visual-speed-estimator corrected_kalman`；`--sim-visual-speed-estimator constant_fit` 使用本文的恒速拟合，`--sim-visual-speed-estimator kalman` 切换回原始卡尔曼预测。`--sim-speed-position-source legacy_center` 可回退到原始位置观测。`--fixed-prediction-speed-m-s` 显式指定时仍优先使用设定速度。原卡尔曼跟踪、视觉目标关联和速度有效性判定仍参与冻结前资格检查，拟合结果不替代这些模块。抓取日志中的 `frozen_speed_comparison` 记录同帧估计、拟合样本数、跨度、位置残差以及实际控制来源。RGB-D 窗口与 MuJoCo 窗口列出各方法结果。

## 历史回放

```bash
cd /home/ubuntu22/nero_conveyor_ros2
PYTHONPATH=src/nero_core OPENBLAS_NUM_THREADS=1 python3 tools/compare_constant_speed_replay.py \
  runs/random_five_15cms_20261103/frozen_cloud_visual.json \
  --output runs/random_five_15cms_20261103/constant_fit_replay.json
```

对这四件工件，在第二次冻结时使用的视觉位置做因果回放；另外以模拟器记录的工件位置进行事后评估。评估截止于计划接触前 0.6 秒，以避免闭爪接触影响。模拟器位置每 0.5 秒记录一次并线性插值；以下仅为速度误差造成的沿带预测位置误差，不含初始位置与执行误差：

| 工件 | 卡尔曼误差 mm | 恒速拟合误差 mm |
|---|---:|---:|
| 1 | -6.64 | -2.85 |
| 2 | -13.70 | -12.69 |
| 3 | -4.41 | -9.94 |
| 4 | -14.30 | -8.69 |

平均绝对误差约 9.76 mm 与 8.54 mm。样本少，第三件变差，说明较长历史可能带入视角相关系统漂移，拟合模型也不能消除这一问题；不能据此推断真机精度或普遍提升。该实验未修改真机抓取算法和参数。

## 实际控制链仿真

`runs/random_five_15cms_20261103/constant_fit_live.json` 使用恒速拟合作为控制速度，15 cm/s、五件随机 T-LESS、不同初始偏角；五件均完成模拟抓取、放置和返回。`constant_fit_live_comparison.json` 用同一批冻结观测对照卡尔曼：按上述接触前区间计算，五件的平均绝对速度相关位置误差分别为卡尔曼 **7.88 mm**、拟合 **8.04 mm**。五件中拟合三件较小、两件较大；这次运行不能证明拟合更准确，也不能将抓取成功归因于测速。物理仿真结果不代表真机表现。
