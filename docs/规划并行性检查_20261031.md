# 规划并行性检查与只读场景原型（2026-10-31）

## 已确认可重叠

当前真机拦截规划串行执行：候选边界 → 该候选逐点 IK → 关节曲线 → 场景安装/索引 → 几何检查。带面场景点云筛选、体素降采样和空间索引依赖当前冻结帧和标定，不依赖最终选中的 OBB 抓姿；目标点云索引也不依赖该抓姿。因此，在拿到不可变目标后，可以与第一候选的 IK 并行准备，等待完整结果之后才安装到规划器并认证实际选中的曲线。

当前视觉的目标几何工作线程已和相机跟踪线程并行；OBB 仍要依赖目标点云，但该数据的离线 OBB 约几毫秒，不能把未使用的网络推理当作并行收益。各 IK 点当前用前一点的解作种子，同一条轨迹的节点不能直接独立拆线程而维持原有逆解分支。

## 离线只读原型

`tools/benchmark_parallel_scene.py` 仅用于保存帧回放。原型对目标的本帧场景点、像素索引和带面参数先复制为只读快照；后台线程只使用私有模型占位对象构建场景和索引，不读写实际规划机器人的可变 MuJoCo 数据。规划线程求逆解；仅收到本次目标的结果后才提交到规划器。

对 `record_20261030_232939` 的 271、301 帧，在 0.0595 m/s 固定速度、当前 10 Hz IK / 50 Hz 规划几何采样下，以默认和候选等待位分别交替执行 3 组串行及并行，共 12 对；计时包括快照复制、线程启动和最终等待：

| 假定等待位 | 串行规划中位数 | 并行原型中位数 | 差值 |
|---|---:|---:|---:|
| 当前默认等待位 | 0.534 s | 0.457 s | 约 77 ms，14% |
| 仿真换算候选等待位 | 0.363 s | 0.287 s | 约 76 ms，21% |

后台场景计算本身中位数约 126～131 ms，复制快照约 5～6 ms，主线程在场景完成处等待中位数约 4～7 ms；场景计算与 IK 重叠，不能将这些时间与总耗时相加。实际耗时受到 CPU、并发负载和点云规模影响，两帧样本不足以给出现场最坏时间。

12 对回放均交付轨迹，逐对选中抓姿、候选通过/拒绝原因、带面场景点数组哈希及目标索引数据哈希相同。每帧每种等待位的第一组对照中，501 个时刻的 7 轴位置、速度和加速度逐值一致。检测使用假定的拍摄等待位进行自体过滤，规划从指定等待位开始；这些并非真实实时机器人反馈。数据见 `runs/parallel_scene_benchmark_20261031/snapshot_*`，没有设备连接或真机命令。

## 还不能认为已经部署

**该原型没有接入真机或仿真主规划入口，原程序仍串行执行场景准备。**基准工具是局部原型，线程上下文在失败退出时仍可能等待后台工作结束；它没有完整验证规划取消、相机时钟重置、目标切换、超时和晚到结果销毁的组合。正式接入前须给每份快照绑定任务、目标、帧、时钟代次和标定版本；旧结果只能丢弃，不得提交给新轨迹；要验证取消不被长时间等待拖住，并在规划失败时处理线程资源。不得并行共享可变 MuJoCo `MjData` 或混用两帧场景。

其他可进一步探索的并行项包括独立候选抓姿或多个 IK 分支、已生成曲线上的几何采样批处理；它们需要各自私有模型数据、按相同候选策略归并和预算控制，GIL/内存争用可能抵消收益，本次没有跑出可宣称的性能数字。载物路径依赖实际夹持反馈和到位状态，不能将事先猜测的轨迹直接执行；可预先准备不依赖载物状态的数据，再在反馈到达后重算与检查。

## 重现

在项目目录分别用 `NERO_PARALLEL_SCENE_EXPERIMENT=0` 和 `=1` 运行相同回放：

```bash
cd /home/ubuntu22/nero_conveyor_ros2
PYTHONPATH=src/nero_core:tools OPENBLAS_NUM_THREADS=1 NERO_PARALLEL_SCENE_EXPERIMENT=1 \
  python3 tools/benchmark_parallel_scene.py \
  --run runs/two_second_hardware/record_20261030_232939 \
  --config src/nero_bringup/config/two_second.hardware.legacy_observed.yaml \
  --frame 271 --speed 0.0595 \
  --output runs/parallel_scene_benchmark_20261031/example.json
```

只读快照隔离、目标身份保护和相关碰撞、规划回归共 61 项通过，日志 `runs/parallel_scene_benchmark_20261031/pytest.log`。该原型不连接相机或 CAN，也不发送控制命令。
