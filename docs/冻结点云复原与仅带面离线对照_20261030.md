# 冻结点云复原与仅带面离线对照

本次复查对象为 `runs/two_second_hardware/test_20261030_201439_824446187/`。此前“没有保存原始 RGB 和全场景”的表述不准确：没有保存的是该次 **scene_collision 分支的完整过滤场景诊断包**；但 `preview/target.npz` 保存了冻结目标所属的 RGB、原生深度、内外参、曝光时间和目标点云，可以还原整帧原始点云。

## 当帧证据

复原工具只读取 `preview/target.npz`，不使用之后的 `preview/latest.npz` 替代。先核对 `qualified_target` 的目标身份 `[0,1,118]`、帧序号 `251`、设备时间 `2807.109891 s`、时钟代次及曝光单调时间，再反投影。

- 原生有效深度点：902,204；已选目标点：1,751。
- 记录中的告警点可在原始深度像素 `(u=457,v=366)` 精确找到，双精度坐标差为 0 m。
- 该像素深度为约 776 mm；其 RGB 标定投影为 `(447.599,326.892)`。
- 5 mm 半径内有 30 个原始点；10 mm 内 45 个；40 mm 内 494 个，均包含点自身。这些是**原始点云**的邻域数量，不代表碰撞过滤后保留了多少点。
- 原生 5×5 邻域有 20 个有效像素，深度约 774–776 mm，其余 5 个像素无效。没有补点、填洞或去噪。

RGB 投影靠近夹爪与背景交界，深度图可见明显的无效深度边界。机器人边缘残留、边界深度异常均值得检查，但单帧不能确认点的物理归属。颜色只是利用真实标定投影；在遮挡边界可能落到背景颜色，不能把投影处颜色当作物体分类结果。“仅一个点触发”也不等于原始点云只有一个孤立噪声点。

结果在 `runs/pointcloud_recovery_20261030_201439_verified/`：

- `pointcloud_overview.png`：同帧 RGB、作业区点云显示抽样、原生深度局部、40 mm 点云邻域；红圈/红点表示日志中的告警坐标。
- `rgb_trigger_crop.png` 和 `raw_rgb.png`：原始 RGB 局部投影及整图。
- `native_pointcloud.ply`：所有有效原生点，基座系，米，double 精度，包含原始深度像素 u/v。没有应用场景过滤、自体过滤或点云降采样。
- `trigger_neighborhood.ply`：40 mm 内全部原始点。
- `report.json`：源文件哈希、时间、身份、像素匹配、邻域数量与离线对照。

## 仅带面离线对照的范围

按用户提出的“只考虑传送带”，工具增加了明确隔离的**保存姿态离线对照**：不将场景点作为拒绝条件，保留私有机器人模型的关节范围和自碰撞检查，并采用 `MeasuredPlanner.valid` 原有的夹爪顶点/带面谓词。

带面由本次冻结 RGB-D 重新拟合，不冒充运行时较早缓存的原带面；不是新填造的固定高度。第一个被拒绝姿态（轨迹 0.600 s）及第二个姿态（0.615 s）都通过这项带面检查，带面范围内最低夹爪顶点分别约高于带面 77.350 mm 和 77.419 mm；原有场景告警仍记录在报告中。

这只检查两个保存姿态，没有恢复或认证整条轨迹，没有对传送带边框建立实体碰撞模型，也没有证明载物转运安全。工具无设备接入和发送能力，真机配置、碰撞检查、发送所有权及闭合门槛均未改变。确认原告警点来源前，没有把“忽略其他障碍”部署到真机。

## 复现

本工具位于源码 `tools/`，无需重新构建 ROS 包。输出目录必须是新目录：

```bash
cd /home/ubuntu22/nero_conveyor_ros2
OPENBLAS_NUM_THREADS=1 MUJOCO_GL=egl PYTHONPATH=src/nero_core \
python3 tools/recover_saved_pointcloud.py \
  --run runs/two_second_hardware/test_20261030_201439_824446187 \
  --config src/nero_bringup/config/two_second.hardware.legacy_observed.yaml \
  --output "runs/frozen_pointcloud_$(date +%Y%m%d_%H%M%S_%N)"
```

复查包括帧身份配对、告警坐标精确匹配、PLY 二进制坐标及像素回读、错误帧拒绝、带面对照和源文件哈希核对。未连接相机、机械臂或 CAN；不把离线结果算作真机抓取成功。
