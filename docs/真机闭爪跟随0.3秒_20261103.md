# 真机闭爪后 0.3 秒同速跟随

用户要求将 `two_second.hardware.legacy_observed.yaml` 的闭爪后同速跟随从 0.8 秒缩短至 0.3 秒。当前参数是同步接入末端定时尝试闭爪，同速 0.3 秒，接着 0.5 秒减速。减速不等于立刻静止，实际位移取决于轨迹和设备跟踪。

夹持确认仍由实际闭爪命令完成后的宽度、力和新反馈时间组成，要求有效反馈持续 0.4 秒，未缩短确认时间。`scheduled_attempt` 下确认可以在减速过程中继续；流结束未确认夹持则不进入载物抬升。配置层仅允许平滑同步定时闭爪模式使用短于 0.4 秒的同速段，并要求跟随与减速时间之和超过原确认时间。实际夹爪闭合及反馈可能更慢，因此这个必要条件不能保证确认必然完成。

已对 11.76 cm/s 记录中的历史目标和速度做时序回归，模拟的跟随末端在设定区间内，但并非完整现场轨迹认证。测试包含理想反馈夹持在减速期间确认、空爪未确认及短跟随不兼容策略拒绝：136 项通过、6 项不适用组合跳过。`nero_core`、`nero_bringup` 构建通过；安装后的 `--check-config` 显示视觉测速、跟随 0.3 秒、减速 0.5 秒，没有打开设备或发送命令。

测试替身不代表实际夹爪性能；这次没有重新进行物理仿真、实机运行或验证实测夹持成功。运行中的旧进程需退出重启才加载新参数。
